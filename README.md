# Business Income Tracker

A mobile application built with **Java** in **Android Studio** that helps small business owners and entrepreneurs track their income, analyze earnings, and generate financial statements.

## 📱 Overview

Business Income Tracker allows users to record different sources of business income in one place. The app provides visual insights through charts and enables users to generate printable income statements, making it easier to monitor business performance over time.

## ✨ Features

- 💰 Record income from multiple income categories
- 📊 Visualize income using interactive charts
- 📄 Generate and print income statements
- 📅 Track income over time
- 📈 Monitor business performance and trends
- 📱 Simple and user-friendly Android interface

## 🛠️ Built With

- **Java**
- **Android Studio**
- **SQLite** (or replace with your database if different)
- **MPAndroidChart** (replace if you used another chart library)
- Android SDK

## 🚀 Installation

1. Clone the repository.

2. Open the project in Android Studio.

3. Allow Gradle to download the required dependencies.

4. Build and run the application on an Android device or emulator.

## 📖 How to Use

1. Launch the application.
2. Add income entries by selecting the appropriate income category.
3. View all recorded income.
4. Analyze your business performance through the Charts section.
5. Generate and print income statements whenever needed.
